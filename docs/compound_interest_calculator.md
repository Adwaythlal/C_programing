## This C program is used to calculate compound interest.

- The user enters the principal amount.
- The user enters the interest rate.
- The user enters the number of years.
- The user enters the number of times the interest is compounded per year.
- The program uses the compound interest formula:

A = P × (1 + r/n)ⁿᵗ

#### Finally, it displays the total amount after the given number of years.
