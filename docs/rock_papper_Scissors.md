### Program Description
This is a Rock Paper Scissors game in C where the user plays against the computer. The computer randomly selects an option, and the program determines the winner based on the rules of the game.
### What I Learned
- How to create and use user-defined functions in C.
- How to generate random choices using rand() and srand().
- How to use switch statements to display choices.
- How to use do-while loops for input validation.
- How to use if-else statements and logical operators to determine the winner.
- How to pass arguments to functions and return values.
- How to organize a program using function declarations and definitions.
