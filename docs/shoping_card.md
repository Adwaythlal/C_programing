# What I Learned

## Through this program, I learned the fundamentals of C programming, including:

- Declaring and initializing variables.
- Using different data types such as char, int, and float.
- Taking user input using fgets() and scanf().
- Working with strings using strlen().

- Using formatted output with printf().
- Using arrays to store strings.
- Understanding the basic structure of a C program, including main() and return 0.
- Using a simple calculation to process user input and produce an output.
