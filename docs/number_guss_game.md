### Program Description
This is a number guessing game in C where the computer generates a random number between 1 and 100, and the user tries to guess it. The program provides hints if the guess is too high or too low and displays the total number of attempts.
### What I Learned
- How to generate random numbers using rand() and srand().
- How to use time(NULL) to initialize random number generation.
- How to use a do-while loop to repeat the game until the correct answer is guessed.
- How to use if-else statements to check the user's guess.
- How to count the number of attempts using a variable.
- How to use comparison operators and display results using printf().
