### Program Description

This is a simple quiz game in C that asks the user multiple-choice questions, checks their answers against an answer key, and displays the final score.

### What I Learned

- How to use two-dimensional character arrays to store questions and options.

- How to use arrays to store the correct answers.

- How to use a for loop to display questions one by one.

- How to use sizeof() to calculate the number of questions.

- How to use toupper() to convert lowercase answers to uppercase.

- How to use if-else statements to check answers.

- How to calculate and display the final score.
