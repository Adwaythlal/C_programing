### Program Description

This is a simple banking program in C that allows users to check their balance, deposit money, and withdraw money through a menu-driven interface.

### What I Learned

- How to create and use user-defined functions in C.

- How to use switch statements to handle menu options.

- How to use a do-while loop to repeat the banking menu.

- How to pass arguments to functions and return values.

- How to perform arithmetic operations to update the balance.

- How to use if-else statements to validate deposits and withdrawals.

- How to handle invalid choices and insufficient funds.
